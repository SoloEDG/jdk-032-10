# 骨牌造境 / Chainline

一个本地运行的多米诺链设计、顺序模拟与参数可识别性校准工作台。

## 校准实验室

- 每条试验链样本都会保存节点坐标、摆放尺寸、牌高/牌宽、起倒门槛、摆放误差和使用地面。
- 拟合不会只返回一组“恰好能跑”的参数，而是枚举地面摩擦、牌面摩擦、触发距离修正和双面提前量的参数网格，保留所有能复现真实倒下顺序的组合。
- 面板会分别显示：
  - 哪些参数区间真正收窄；
  - 哪些参数仍覆盖整个先验；
  - 摩擦与触发距离之间的相关/补偿关系；
  - 由样本共同限制的联合接触预算；
  - 每条样本单独的筛选强度。
- `保留：双面分岔链` 默认不参与拟合。拟合后会用全部可行参数检查 A/B 两面的预测；若同时存在 A 先和 B 先的可行组合，会给出两组具体“相反预测见证参数”。
- 修改样本后状态会标记为“待重新拟合”。新的模拟运行会把当时的参数区间、代表候选、相关性和分岔预测冻结进 `SimulationRun.calibrationSnapshot`；之后重新拟合不会改写旧回顾。

当前顺序校准使用轻量事件/接触模型，适合做参数可识别性与分岔方向检验；它不是连续刚体力学求解器，界面中也不应把可行集表述成唯一物理真值。

## 本地启动

```sh
npm ci
npm run dev
```

在浏览器打开 Vite 输出的本地地址。

## 质量检查

```sh
npm run typecheck
npm run build
```

## Docker 启动

```sh
docker compose up --build
```

打开 <http://localhost:8032>。端口可通过 `DOMINO_LAB_PORT` 修改。
